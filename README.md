# Note Width Changer

A tiny plugin that does one thing: it changes the width of your notes. That's it. 🙂

Obsidian only lets you pick **narrow** (with big empty margins) or **full width**. This plugin lets you pick **any width you like**, and it changes all of your notes at once.

No extra features, no big toolkit, nothing else to learn. Just drag a slider and your notes get wider or narrower.

## What it does

- Set the text width in **pixels** (stays the same on any window size) or **percent** (grows and shrinks with the window).
- **Live slider**: the note changes width as you drag, both in the quick popup and in the plugin settings.
- **Status bar button**: shows the current width (like `↔ 1000px`). Click it to open the slider and quick presets.
- Works in **editing view** and **reading view**.
- Works whether Obsidian's own "Readable line length" option is on or off.
- **Commands** you can put on hotkeys: *Make text wider*, *Make text narrower*, *Adjust text width…*, *Turn custom width on/off*.

## How to use it

1. Install and turn on the plugin.
2. Click `↔ 1000px` in the bottom status bar.
3. Drag the slider until the width feels right. That's it, it saves on its own.

You can also change it in **Settings → Note Width Changer**.

## Install

**From Obsidian:** Settings → Community plugins → Browse → search **Note Width Changer** → Install → Enable.

**By hand:** download `main.js`, `manifest.json` and `styles.css` from the [latest release](https://github.com/pramodexe/obsidian-note-width-changer/releases/latest) and put them in a folder called `note-width-changer` inside your vault's `.obsidian/plugins/` folder. Then turn it on in Settings → Community plugins.
